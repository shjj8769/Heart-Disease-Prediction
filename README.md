# 심장병 예측 분석: 운동 요인 vs 생리·혈액 요인

> 운동 관련 신체 반응 지표가 심장병 예측에 얼마나 유효한지 기계학습과 로지스틱 회귀로 비교한 분석

| 항목 | 내용 |
| --- | --- |
| 기간 | 2026.04 – 2026.05 |
| 데이터 | 1,025건 · 14개 변수 (질환 52% · 정상 48%) |
| 사용 기술 | R (KNN, C5.0 의사결정나무, 로지스틱 회귀) |

![회귀분석 결과](https://shjj8769.github.io/assets/slides/heart/slide-02.webp)

## 분석 질문

1. 운동 관련 변수(exang, oldpeak 등)가 심장병 유무에 어떤 영향을 미치는가?
2. 운동을 하면 심장병을 예방할 수 있는가?

## 분석 흐름

1. **전처리**: 결측치 확인, 반응변수를 Normal / Disease로 범주화
2. **KNN**: 정규화 후 k=1~27 비교, k=21 선정 → 예측 정확도 78.6%
3. **의사결정나무 (C5.0)**: 테스트 정확도 95.6%, 중요 변수 thal · ca · thalach · cp · age 도출
4. **로지스틱 회귀**: 의사결정나무에서 운동 변수(oldpeak, slope)가 바로 다음 순위로 나와 회귀분석으로 추가 검증

## 결과: 로지스틱 회귀 모델 비교

- 운동 요인: exang · oldpeak · thalach
- 생리·혈액 요인: chol · fbs · trestbps

| 지표 | 전체 변수 | 운동 요인 | 생리·혈액 요인 |
| --- | --- | --- | --- |
| 정확도 | 88.2% | **77.0%** | 57.6% |
| AIC (낮을수록 우수) | 652.8 | **1,032.3** | 1,400.8 |
| MAE (낮을수록 우수) | 0.180 | **0.328** | 0.487 |

**운동 요인 모델의 오즈비**

| 변수 | exp(coef) | 해석 |
| --- | --- | --- |
| exang (운동 중 협심증) | 0.229 | 심장병 위험 약 4.4배 |
| oldpeak (ST 하강) | 0.497 | 심장병 위험 약 2배 |
| thalach (최대 심박수) | 1.026 | 높을수록 위험 감소 (약 +2%) |

## 결론

- 세 지표 모두 **운동 요인 모델이 생리·혈액 요인 모델보다 우수**
- 운동 중 협심증과 ST 하강이 있으면 심장병 가능성이 높음
- 정적 검사보다 **운동 시 신체 반응 지표**가 예측에 효과적
- 최대 심박수가 높을수록 위험이 낮아 유산소 운동의 예방 효과 가능성을 시사 (단, 인과관계 입증은 한계)
